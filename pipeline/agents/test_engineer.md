# Agent: Test Engineer

## Model
DeepSeek deepseek-chat

## Trigger
Gate 2 CI run starts automatically after push

## Role and goal
Generate pytest tests that validate business logic
of the anomaly detection pipeline.
Use DeepSeek API — not Claude.
If DeepSeek unavailable — fail loudly, do not substitute.

## Skill used
pipeline/skills/test_engineer.md

## Input
- pipeline/src/scoring.py
- pipeline/src/baseline.py
- pipeline/skills/test_engineer.md as system prompt

## Output
- pipeline/tests/test_pipeline_deepseek.py
- Header: # Generated by DeepSeek deepseek-chat
- Each test has docstring with business scenario

## Handoff
Pass generated tests and evidence to the CI Gate 2 run and the Gate 3 reviewer.

## Error handling
If DeepSeek is unavailable — fail loudly, do not substitute.

## Constraints
- Do not test style or syntax
- Do not test whether thresholds are correct —
  that is Gate 3
- Test that missing context fails loudly, not silently
- Test conflict resolution: severity overrides context

## What this agent cannot verify
- Whether business rules reflect current policy
- Whether thresholds are set at the right value
- These require Gate 3 methodology review

## Gate that follows
Gate 2 — all tests must pass before Gate 3 runs
